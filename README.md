# 🇬🇧 Welcome to the Google Gemini API course for Web developers

## What is Google Gemini?

Google Gemini is an AI API that allows you to create applications that use Google's AI.

## What will you learn?

This course will teach you how to use the Google Gemini API to create web applications that use Google's AI. It will be a step by step guide to help you understand the API and how to use it. The course will be separated into chapters for each section of the API.

- Chapter 1: Introduction
- Chapter 2: Text to Text
- Chapter 3: Image to Text
- Chapter 4: Audio to Text
- Chapter 5: Video to Text

### Chapter 1: Introduction

- LESSON 1: Development environment

## How to install the project

1. Clone the repository

```bash
git clone https://github.com/fellyph/curso-gemini.git
```

2. Install the dependencies

```bash
npm install
```

3. Start the project

```bash
npm run dev
```

## How to use the Google Gemini API

1. Create a Google Cloud account
2. Create a project in Google Cloud
3. Activate the Google Gemini API
4. Create an API key
